# astrbot_plugin_bio_cycle · 生理周期拟真

> 让你的电子伴侣拥有真实可信的**生理周期节律**——身体状态、情绪与语气会随月经周期自然起伏，
> 像真人一样有节律地变化。可选联动日程、好感度、主动消息等插件，打造完整的「赛博生命体」。

适用于把 AstrBot 用作拟人化伴侣/角色扮演的场景。**单独安装即可使用**，所有联动插件均为可选。

---

## ✨ 它做了什么

把一个完整月经周期划分为 5 个阶段，每个阶段对应不同的身体感受与情绪基调，并自然注入到角色的
对话状态中（不生硬报告，只融进语气与精力）：

| 阶段 | 时机 | 身体与情绪倾向 |
|------|------|----------------|
| 🩸 经期 | 第 1 ~ N 天 | 慵懒易累、小腹坠胀、怕冷想喝热的、需要被照顾 |
| 🌱 卵泡期 | 经期后 ~ 排卵前 | 精力回升、心情转晴、有干劲 |
| ☀️ 排卵期 | 周期中点 ±2 天 | 状态巅峰、活力心情最好、外向有神采 |
| 🌗 黄体期 | 排卵后 ~ 经前 | 平稳温和、踏实顾家 |
| 🌧️ 经前期(PMS) | 周期最后约 4 天 | 敏感、情绪起伏、嘴馋想吃甜、需要包容 |

排卵点以「下次经期前 14 天」为锚（符合黄体期长度恒定的生理规律），所以**自定义周期长度时阶段会
自动按比例重排**，无需手动调整。经期开始日可以是过去任意一次，插件按周期长度取模**自动滚动**到
当前周期，不必频繁更新。

## 🚀 快速开始

1. 在插件市场安装本插件并重启 AstrBot。
2. 私聊或群里发送（管理员）：
   ```
   /周期 设定 今天          # 或 /周期 设定 2026-05-20
   ```
3. 完成。之后角色在对话中就会自然体现当前所处生理阶段的身体状态。随时 `/周期` 查看当前阶段。

### 命令

| 命令 | 权限 | 说明 |
|------|------|------|
| `/周期` | 所有人 | 查看当前阶段、周期第几天、距下次经期 |
| `/周期 设定 2026-05-20` | 管理员 | 设定最近一次经期开始日（支持 `今天`）|
| `/周期 长度 28` | 管理员 | 设定平均周期天数（15~45）|
| `/周期 经期 5` | 管理员 | 设定经期持续天数（1~10）|
| `/周期 开启` / `/周期 关闭` | 管理员 | 运行时开关 |

### 配置项

| 配置 | 默认 | 说明 |
|------|------|------|
| `enable` | true | 总开关 |
| `character_name` | 晚宁 | 角色名，建议与 time_prompt 等插件保持一致 |
| `intensity` | subtle | `subtle` 细腻自然（只在语气精力上体现）/ `moderate` 明显戏剧化 |
| `intimacy_favour_threshold` | 60 | 流露私密状态的好感度阈值（联动 favorpro，见下） |
| `intimacy_relationship_keywords` | 男友/老公/恋人… | 亲密关系关键词 |

## 🔗 插件联动效果（全部可选）

bio_cycle 设计为可与一系列拟人化插件协同，构成更完整的「此刻的她」。联动分两类，**安装难度不同，请按需选择**：

### ✅ 开箱即用联动（装了对应插件即自动生效，无需任何额外操作）

#### favorpro（好感度系统）—— 私密状态的亲密度门控
> 仓库：https://github.com/Catfish872/astrbot_plugin_favourpro

经期不适、撒娇想被照顾这类**私密表达**，只有当对话者满足「关系含恋人类关键词 **且** 好感度 ≥ 阈值
（默认 60）」时才会自然流露；否则只在语气、精力上隐约体现，不主动提私密细节。

bio_cycle 是**单向读取** favorpro 的关系/好感数据来做这个判断的，所以**只要装了 favorpro 就自动生效**，
不需要改任何代码。未装 favorpro 时降级为「只体现语气、不流露私密状态」。

#### time_prompt（时间观念）—— 周期状态与时间锚点共存
> 仓库：https://github.com/wuyan1003/time_prompt

两者各自向对话注入状态、互不干扰：time_prompt 负责「现在几点、距上次聊天多久」，bio_cycle 负责
「身体处于周期哪个阶段」。装了 time_prompt，角色对话就同时具备时间感与身体节律感。建议把两边的
角色名配置成一致。

### 🛠️ 进阶联动（需要给对应插件打补丁，补丁见 [`patches/`](patches/)）

以下效果需要让对方插件**主动调用** bio_cycle 的接口，因此要对它们的源码做一处轻量改造
（补丁已附在 `patches/` 目录，附 `git apply` / `patch` 应用说明与失败时的手动添加指引）。
**不打补丁完全不影响本插件核心功能**，只是日程和主动消息不会随周期变化而已。

#### life_scheduler（拟人化生活日程）—— 日程随周期起伏
> 仓库：https://github.com/muyouzhi6/astrbot_plugin_life_scheduler ｜ 补丁：`patches/life_scheduler.patch`

打补丁后，每日自动生成的日程会**随生理阶段调整**：经期那几天日程偏居家休息、热饮、早睡；
排卵期偏外出运动社交。让「日程」和「身体」真正一致。

#### daily_sharing（定时主动分享）—— 主动动态带身体状态
> 仓库：https://github.com/siciyuanweilai/astrbot_plugin_daily_sharing ｜ 补丁：`patches/daily_sharing.patch`

打补丁后，角色**主动**发的分享/动态也会结合当前身体状态与（私聊对象的）好感关系。补丁同时新增了
一个 `inject_persona_state` 开关（默认开）让你随时关闭。

#### proactive_chat（主动消息）—— 主动找你聊天时也「在状态里」
> 仓库：https://github.com/DBJD-CR/astrbot_plugin_proactive_chat ｜ 补丁：`patches/proactive_chat.patch`

proactive_chat 原本主动发消息时不带任何实时状态。打补丁后，主动消息会带上**时间 + 日程 + 生理周期 +
好感关系**四层状态。私聊且关系够亲密时，她经期主动找你还会自然撒娇说不舒服；群聊则自动降级（不暴露
对单人的好感、不群发私密状态）。

> 主动链路联动（daily_sharing / proactive_chat）若要注入好感关系，还需一并应用 `patches/favorpro.patch`
> （给 favorpro 增加一个**只读**的好感锚接口）。详见 [`patches/README.md`](patches/README.md)。

## 📦 数据与原理

- 状态存于 `data/plugin_data/astrbot_plugin_bio_cycle/cycle_data.json`，含经期开始日、周期/经期长度、历史记录。
- 生理周期是角色**本人**的身体状态，**全局唯一**（与跟谁聊天无关），这与 favorpro 那种「对每个用户
  独立的好感度」有本质区别。
- 注入方式：`@filter.on_llm_request(priority=-10)`，排在日程/时间（默认 0）之后、好感度格式指令（-20）
  之前，使身体状态出现在合理的层次上。

## 🧩 给开发者：对外接口

供其他插件联动调用（`patches/` 里的补丁正是调用它们）：

- `get_cycle_context() -> dict`：当前阶段、周期天序、身体状态、日程倾向。
- `build_external_cycle_anchor(session_key, *, purpose="active_share", favour=None, relationship=None) -> str`：
  可叠加进 system_prompt 的身体状态文本，支持亲密度门控，供绕过 `on_llm_request` 的主动推送链路复用。

接口契约详见 [`patches/README.md`](patches/README.md)。
